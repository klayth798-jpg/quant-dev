# Quant Dev 前端操作手册

本文档对应 2026 年 6 月 9 日的前端和 API 行为。

## 1. 启动工作台

在项目目录执行：

```bash
make dev
```

浏览器打开：

```text
http://127.0.0.1:8000
```

接口文档：

```text
http://127.0.0.1:8000/docs
```

页面右上角的“刷新”会重新加载首页、因子、回测、证券、数据状态、指数和模拟账户。

## 2. 推荐使用顺序

第一次使用真实数据时，推荐按以下顺序操作：

1. 数据中心确认真实数据已配置并同步。
2. 因子实验室评估候选因子。
3. 策略回测验证收益、回撤、成本和股票池。
4. 风险检查验证目标组合。
5. 模拟交易提交小额委托。
6. 研究 Agent 汇总因子和回测证据。

## 3. 总览

总览页用于快速判断研究环境是否可用。

### 顶部指标

- 数据快照：当前活动 `snapshot_id`。
- 证券数量：当前快照中有行情的标的数。
- 行情记录：当前快照的日线总行数。
- 因子数量：已经注册的因子数。

### 系统状态

- 研究数据库、因子引擎和回测引擎应显示健康。
- 实盘交易固定显示禁用。
- 禁用实盘不影响回测、风控和模拟交易。

### 最近回测

首页展示最近的回测结果和净值曲线。需要查看或生成新实验时进入“策略回测”。

## 4. 数据中心

### 4.1 配置状态

页面顶部会显示当前使用 Tinyshare 还是官方 Tushare，以及财务接口模式。

如果显示未配置：

1. 在项目根目录创建或修改 `.env`。
2. 填写 `MARKET_DATA_SDK` 和对应 Token。
3. 重启 `make dev`。

Token 不会显示在页面，也不会写入数据库。

### 4.2 同步日期

- 开始日期和结束日期均包含在同步区间内。
- 第一次同步建议先选 1 至 3 年验证稳定性。
- 日常更新只需要从数据库最新日期附近同步到当前日期。
- 已存在的交易日会自动跳过。

### 4.3 指数代码

多个指数用逗号分隔，例如：

```text
000300.SH, 000905.SH, 000852.SH
```

只有同步了历史成分的指数，才能在回测中作为时点股票池使用。

### 4.4 财务股票上限

当 `TUSHARE_FINANCIAL_VIP=false` 时，普通财务接口按股票调用，这个字段控制最多同步多少只股票。

当 VIP 模式启用时，字段禁用，系统按季度报告期同步全市场财务指标。

### 4.5 数据模块

可独立勾选：

- 日线与每日指标。
- 财务指标。
- 指数与历史成分。

只更新每日行情时，可以关闭财务和指数模块，减少调用时间。

### 4.6 任务状态

点击“开始同步”后会创建后台任务。

| 状态 | 含义 |
| --- | --- |
| `queued` | 已入队，尚未开始 |
| `running` | 正在调用数据接口和写库 |
| `completed` | 全部请求流程完成 |
| `failed` | 发生错误，页面显示原因 |
| `interrupted` | 任务被手动中断 |

任务完成不代表每个交易日一定覆盖全市场。正式使用前应结合行数、缺失率和异常检查确认数据质量。

## 5. 因子实验室

### 5.1 选择评估参数

页面顶部可设置：

- 预测周期：1 至 60 个交易日。
- 行业市值中性化：是或否。

预测周期表示因子值与未来多少个交易日的收益做相关性评估。常用值：

| 场景 | 建议周期 |
| --- | ---: |
| 短周期反转 | 1 至 5 |
| 周频选股 | 5 |
| 月频动量 | 20 |

### 5.2 重新评估

在目标因子行点击“重新评估”。计算完成后页面会刷新最近指标。

全市场真实库包含数百万行数据，中性化评估需要加载市值面板，运行时间和内存占用明显高于普通评估。

### 5.3 指标解释

| 列 | 解释 |
| --- | --- |
| IC | 因子排名与未来收益排名的平均相关性 |
| ICIR | IC 的稳定性指标 |
| 多空年化 | 顶部三分组减底部三分组的近似年化收益 |
| 版本 | 因子定义版本 |

判断因子时不要只看 IC 正负，还要结合：

- 正 IC 比例和样本覆盖。
- 不同预测周期是否稳定。
- 中性化前后差异。
- 不同年份和市场状态。
- 成本后回测和换手率。

## 6. 策略回测

### 6.1 参数说明

| 字段 | 含义 | 使用建议 |
| --- | --- | --- |
| 实验名称 | 保存到回测记录的名称 | 写明因子、股票池和周期 |
| 选股因子 | 排名使用的因子 | 先完成因子评估 |
| 初始资金 | 回测起始现金 | 小资金会更受最低佣金影响 |
| 持仓数量 | 目标持股数 | API 最多 20，页面默认适合少量验证 |
| 调仓周期 | 每隔多少交易日重建目标 | 周频常用 5，月频常用 20 |
| 股票池 | 全市场或历史指数成分 | 指数股票池更可控 |
| 持仓缓冲带 | 保留仍在扩展排名区间的旧持仓 | 1.5x 至 2.0x 常用于降换手 |
| 剔除 ST | 排除名称含 ST 的股票 | 当前使用最新名称近似 |
| 涨跌停约束 | 涨停不买、跌停不卖 | 当前使用规则近似 |
| 行业市值中性化 | 对因子做行业和规模残差化 | 检查收益是否来自暴露 |
| 佣金率 | 双边佣金比例 | 默认 0.0003 |
| 滑点 | 买卖价格冲击，单位 bps | 默认 5 |

卖出印花税固定为 0.0005，当前页面不提供修改入口。

### 6.2 股票池选择

- 全市场：所有有因子值和行情的股票。
- 沪深 300、中证 500、中证 1000：使用历史成分快照。
- 沪深 300 + 中证 500：分别取每个指数在当日之前最近的快照，再合并。

如果提示“没有可用的历史成分数据”，先回到数据中心同步相应指数。

### 6.3 运行回测

点击“开始回测”后：

1. T 日收盘生成因子排名。
2. T+1 日收盘按复权式价格和滑点成交。
3. 先卖出退出或超配持仓，再买入低配持仓。
4. 缺少当日行情的持仓延用上一有效价格估值。
5. 结果和成交记录保存到数据库。

当前回测在 Web 请求内同步执行。全市场大数据回测可能持续较久，不要重复点击。

### 6.4 结果解释

第一组指标：

- 总收益：期末净值相对初始净值。
- 年化收益：按 252 个交易日年化。
- 夏普比率：使用 2% 年化无风险利率。
- 最大回撤：净值峰值到后续谷值的最大跌幅。

第二组指标：

- 超额收益：策略累计净值相对基准累计净值。
- 年化 Alpha：策略年化减基准年化。
- 信息比率：年化 Alpha 除以跟踪误差。
- 超额最大回撤：策略相对基准净值的最大回撤。

图表中的基准是股票池每日等权收益近似，不是交易所发布的指数点位。

## 7. 风险检查

风险检查用于提交目标组合和交易计划的独立验证。

### 7.1 输入

- 标的 1、标的 2：待检查的股票。
- 目标权重：各股票占组合净值的比例。
- 计划换手率：本次计划交易金额占净值。
- 当前回撤：当前组合从峰值回撤。
- 最大单笔委托 / 净值：最大一笔订单金额占净值。

如果两个输入选择同一只股票，系统会先合并权重再检查。

### 7.2 硬规则

| 规则 | 上限 | 严重度 |
| --- | ---: | --- |
| 单标的仓位 | 25% | high |
| 总敞口 | 100% | high |
| 日换手率 | 50% | medium |
| 组合回撤 | 15% | critical |
| 单笔委托 | 20% | high |

结果为：

- `APPROVED`：未触发任何规则。
- `REJECTED`：至少触发一条规则，并显示具体原因。

违规会写入风险事件表。

## 8. 模拟交易

### 8.1 账户信息

页面顶部显示：

- 账户净值。
- 可用现金。
- 持仓市值。
- 相对 1,000,000 元初始资金的累计收益。

持仓按当前活动研究快照中的最新收盘价估值。

### 8.2 提交市价单

1. 选择股票。
2. 选择买入或卖出。
3. 输入 100 股整数倍数量。
4. 委托类型选择“市价”。
5. 点击“提交模拟委托”。

市价单使用最新收盘价和 5 bps 滑点即时模拟成交。

### 8.3 提交限价单

1. 委托类型选择“限价”。
2. 输入限价。
3. 提交订单。

买入限价低于最新价，或卖出限价高于最新价时，订单状态为 `OPEN`。当前版本不会自动重新撮合，也没有撤单按钮。

### 8.4 买单风控

模拟买单会复用风险页的硬规则，使用成交后的预计持仓权重检查：

- 单标的不超过 25%。
- 总敞口不超过 100%。
- 当前账户损失不触发 15% 熔断。
- 单笔委托不超过净值 20%。
- 现金足够支付成交金额和费用。

卖出用于降低风险，不受集中度规则阻断，但必须有足够持仓。

### 8.5 费用

- 佣金 0.03%，最低 5 元。
- 卖出印花税 0.05%。
- 市价滑点 5 bps。
- 买入平均成本包含费用。

### 8.6 订单状态

| 状态 | 含义 |
| --- | --- |
| `FILLED` | 已即时成交并更新账户 |
| `OPEN` | 限价未触及，订单挂起 |
| `REJECTED` | 风控、资金、持仓或参数检查失败 |

每次前端提交会生成新的 `client_order_id`。后端保证同一 ID 的相同请求不会重复成交。

## 9. 研究 Agent

### 9.1 使用方法

1. 输入研究问题。
2. 可选绑定一个因子。
3. 可选绑定一个具体回测，留空则使用最近实验作为证据。
4. 点击“开始分析”。

输出包含文本结论、使用模式和证据对象。

### 9.2 权限边界

Agent 可以读取因子、回测和风险信息，但不能：

- 提交模拟或实盘订单。
- 修改现金。
- 修改持仓。
- 绕过硬风控。

量化交易执行由策略、风控和 OMS 完成，Agent 只承担研究解释和证据组织。

## 10. 常用工作流

### 工作流 A：日常更新

1. 数据中心选择数据库最新日附近到当前日期。
2. 勾选“日线与每日指标”。
3. 非财报期可关闭财务指标。
4. 非指数调整期可关闭指数模块。
5. 等待任务完成并检查写入行数。

### 工作流 B：因子到回测

1. 因子实验室分别评估 5 日和 20 日预测周期。
2. 对比中性化前后的 IC 和多空收益。
3. 策略回测先用指数股票池和默认成本。
4. 对比 5 日、10 日、20 日调仓。
5. 开启缓冲带检查换手下降是否损害收益。
6. 开启 ST 和涨跌停约束做保守场景。

### 工作流 C：模拟交易

1. 根据回测生成少量目标持仓。
2. 在风险页输入目标权重和计划交易规模。
3. 通过后在模拟盘提交小额订单。
4. 检查账户、持仓和订单状态。
5. 使用 Agent 汇总研究证据，不让 Agent 直接执行。

## 11. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 页面显示 Token 未配置 | 修改 `.env` 后必须重启服务 |
| 同步任务失败 | 查看任务行中的错误，检查权限、SDK 和调用频率 |
| 同步写入为 0 | 日期可能已同步，或所选区间无交易日 |
| 回测提示指数无历史成分 | 数据中心同步相应指数和日期 |
| 回测耗时很长 | 当前全量数据在 Python 内存计算，缩小股票池或等待完成 |
| 中性化更慢 | 需要读取完整市值面板并逐日回归 |
| 买单被拒绝 | 检查 25% 单标的、20% 单笔、现金和回撤规则 |
| 卖单被拒绝 | 数量不是 100 股整数倍，或可卖持仓不足 |
| 限价单一直 OPEN | 当前没有持续撮合和撤单功能 |
| Agent 输出较简单 | 当前是本地只读模板，远程研究服务尚未真正调用 |

## 12. 使用边界

- 当前数据活动快照会随同步更新，旧回测不是严格不可变数据复现。
- ST、行业分类和涨跌停仍包含近似或当前状态信息。
- 回测成交使用 T+1 收盘，不代表真实盘中可成交价格。
- 模拟盘没有 T+1 可卖、冻结、撤单、部分成交和券商对账。
- 系统没有登录鉴权，只适合本机或受信网络使用。
- 在完成生产数据治理和 OMS 安全能力前，不应连接真实资金。
